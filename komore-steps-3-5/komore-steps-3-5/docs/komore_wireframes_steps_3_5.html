How the scheduler fills the day (for the Step 5 logic)

OrderRule
1Place all fixed classes for the day first (from classes). They are hard rules.
2Find free gaps between classes, leaving out time the student needs for travel and sleep (from the onboarding profile).
3Sort pending tasks by nearest deadline, then by priority (high first), then by category.
4Put each task into the first gap that fits its estimated time. If it does not fit, split it across gaps or flag it as unplaced.
5Save the result as a new timetable (older one set inactive). Student edits (edited_by_student) are kept on regeneration.
6The AI API suggests improvements on top of this result; the student can always edit the plan.
